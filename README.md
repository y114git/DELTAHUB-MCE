# G3M Mod Creator/Editor

Web-based mod creator and editor for G3M format mods. Create and edit mods without installing G3M.

## Features

- Create local mods and export them as G3M ZIP archives
- Edit local mods by importing existing G3M ZIP archives
- Support for DELTARUNE Chapters 1–5, DELTARUNE DEMO, UNDERTALE, UNDERTALE Yellow, Pizza Tower, Sugary Spire, and FRICKBEARS3
- DATA files and patches, including `.g3mpatch`, xdelta, and `.csx`, plus extra files/folders, icons, tags, and INFO files
- Multi-language support (EN, RU, ZH_CN, ZH_TW, ES, JA, KO)
- Import from G3M and both JSON- and TOML-based Deltamod formats
- Export to the current G3M `mod_config.json` format
